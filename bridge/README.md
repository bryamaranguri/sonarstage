# SonarStage Link

MIDI Remote Script para Ableton Live 12. Conecta Live con la app por OSC.

- No requiere Max for Live (aunque todos los usuarios actuales tienen Suite).
- El asistente de la app lo copia a la carpeta de Remote Scripts del usuario.
- El usuario lo elige en *Preferencias → Link/Tempo/MIDI → Superficie de control*.

Responsabilidades: transporte, posición, locators, loops cuantizados, saltos,
mute de pistas y reporte de estado a la app.

Solo se puede probar en una Mac con Ableton instalado.
